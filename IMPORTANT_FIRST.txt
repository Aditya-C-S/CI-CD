================================================================================
  📋 WHAT YOU NEED TO KNOW
================================================================================

✅ What it does:
   - Predicts if a GitHub commit will break the CI/CD pipeline
   - Analyzes logs from GitHub Actions
   - Finds root causes of failures
   - Suggests fixes with copy-paste commands

✅ Requirements:
   - Python 3.8+
   - GitHub account (for API token)
   - Internet access
   - ~500MB disk space

❌ NOT required:
   - Neo4j (optional for graph features)
   - Docker (optional, use for Neo4j if desired)

================================================================================
  🔑 CRITICAL STEP: GitHub Token
================================================================================

1. Go to: https://github.com/settings/tokens
2. Click: "Generate new token"
3. Scopes needed: repo, read:org
4. Copy the token (starts with "ghp_")
5. Save to .env file:
   GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxxxxxx

⚠️  IMPORTANT: Never share or commit this token!

================================================================================
  🆘 QUICK TROUBLESHOOTING
================================================================================

❌ "ModuleNotFoundError: No module named 'streamlit'"
   → Make sure virtual environment is activated
   → Run: pip install -r requirements.txt

❌ "GITHUB_TOKEN not found"
   → Create .env file in streamlit-dashboard/
   → Add: GITHUB_TOKEN=ghp_xxxx...
   → Get token from: https://github.com/settings/tokens

❌ "Port 8501 already in use"
   → Run: streamlit run app.py --server.port=8502

❌ "Connection refused: localhost:8001"
   → This is normal if you're not running backend services
   → Dashboard still works for basic features

For more help → See SETUP_CHECKLIST.md troubleshooting section

================================================================================
  ❓ FAQ
================================================================================

Q: Do I need Neo4j?
A: No, it's optional. Dashboard works without it.

Q: Do I need Docker?
A: Only if you want Neo4j. Can skip for basic setup.

Q: How long does analysis take?
A: 2-10 seconds per commit.

Q: Does it work on Windows/Mac/Linux?
A: Yes, all platforms supported.

Q: Can I run multiple instances?
A: Yes, on different ports:
   streamlit run app.py --server.port=8502

Q: What's the GitHub token for?
A: Fetches repository data and commits from GitHub API.

Q: Is my token secure?
A: Yes, it's only stored in .env (never committed).

Q: Can I share my project?
A: Yes! But remove .env before sharing.

================================================================================
  💡 PRO TIPS
================================================================================

1. Create a strong GitHub token with limited scopes (repo + read:org only)

2. Keep .env in .gitignore (never commit credentials!)

3. Use virtual environments to avoid dependency conflicts

4. If dashboard is slow, try analyzing smaller repos first

5. Check terminal output for detailed error messages

6. Use curl to test API endpoints:
   curl http://localhost:8501/health
