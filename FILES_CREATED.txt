Project Name: CI/CD Failure Predictor & Graph-Based RCA

What It Does:
  - Predicts if a GitHub commit will break CI/CD pipeline
  - Analyzes GitHub Actions logs
  - Finds root causes of failures
  - Suggests fixes with terminal commands

5 Main Components:
  1. streamlit-dashboard  → Web UI (Streamlit, port 8501)
  2. orc                 → Commit analyzer (Python)
  3. logpipeline        → ML models + log analysis (FastAPI, port 8001)
  4. Metadata-Pipeline  → Git metadata extraction
  5. graph-doc-gen      → Code graph parsing (Neo4j)

3 AI Models Used:
  - Logistic Regression (fast, interpretable)
  - SVM (medium speed, good accuracy)
  - BiLSTM v2 (slow, highest accuracy)
  - Result: Ensemble average of all 3

Requirements:
  - Python 3.8+ ✅
  - GitHub account (for token) ✅
  - Internet access ✅
  - ~500MB disk space ✅
  - Neo4j (optional) ❌ (not required)
  - Docker (optional) ❌ (not required)

Installation Time:
  - Quick setup: 5 minutes
  - Full setup: 30 minutes
